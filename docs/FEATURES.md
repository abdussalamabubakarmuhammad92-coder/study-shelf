> Source: the master blueprint (DeepSeek-assisted) for a "University Resource
> Portal". This is the honest accounting: what shipped as specified, what
> shipped differently and why, and what was consciously dropped.

## 3. Seed data (as specified, then replaced)

- Blueprint: superuser, 9 faculties, 3–5 departments each, 30+ resources,
  test contributor, sample invite — **delivered**, then upgraded:
- Faculties/departments replaced with the owner's **real institutional list**
  (9 faculties, 42 departments).
- Sample resources regenerated as **55 valid PDFs** (real downloadable files,
  generated by the seed command — no external assets needed).
- `seed_data` is idempotent: safe to re-run; skips existing resources.

## 4. Bugs found and fixed during the build (the war stories)

1. **Blank page in production serving** — Vite's default asset paths
   (`/assets/…`) were swallowed by the SPA catch-all, so `<script src>` tags
   received HTML. Fixed with `base: '/static/'`; deep links additionally
   required a regex catch-all (`re_path`) instead of `path('')`.
   → captured in ADR-006.
2. **Expired-token retry loop** — after a silent JWT refresh, retried
   requests re-sent the *old* Authorization header (axios had baked it into
   the request config), so every request 401'd forever despite successful
   refreshes. Fixed by explicitly overwriting the header on the retry.
3. **Admin add-flow test hiccup (test-side, not app-side)** — Django admin
   renders its logout link as a `<form>` earlier in the DOM; the automated
   test submitted it instead of the faculty form. Fixed the selector; the
   app itself was correct.

(`AnonymousUser` serialization crash) — now 401; file-less resources crashed

## 5. Consciously not built (v1 scope line)

- Email sending of invites (manual sharing is a feature, not a gap)
- Thumbnails/previews (needs background workers — ADR-007)
- Pagination (ADR-010), full-text search (roadmap)
- Moderation queue (ADR-008), content-sniffing upload validation (A9)
- Multi-server scaling, CDN, websockets

Each has a written reason and a revisit trigger in the ADRs.
